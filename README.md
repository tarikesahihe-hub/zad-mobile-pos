## إعداد الطابعة WiFi

1. اذهب إلى الإعدادات > إعدادات الطابعة
2. أدخل عنوان IP الخاص بالطابعة (مثال: 192.168.1.100)
3. اضغط "اختبار الطباعة"
4. أو استخدم "البحث عن طابعات" للعثور التلقائي

## تفعيل الترخيص

1. اذهب إلى الإعدادات > الترخيص
2. أدخل مفتاح الترخيص (XXXX-XXXX-XXXX-XXXX)
3. يمكن تفعيل 5 أجهزة لكل ترخيص

## المزامنة السحابية

1. اذهب إلى الإعدادات > مزامنة سحابية
2. أدخل عنوان الخادم
3. اضغط "ربط"
4. ستتم المزامنة تلقائياً
